# 使用这个知识库

这个站点从一个干净的起点重新开始：保留经过整理、验证、未来还会复用的知识，不继续搬运已经过时的内容。

## 内容组织

- `guide/`：知识库自身的使用方式和写作约定。
- `python/`：Python、数据处理与可运行实验。
- `engineering/`：软件工程、系统设计和工具链实践。

新增主题时优先建立清晰的目录，而不是把所有文章堆在同一级。

## 一篇笔记应当包含什么

尽量回答四个问题：

1. 要解决什么问题？
2. 结论是什么？
3. 结论怎样得到或验证？
4. 哪些条件变化后，结论可能失效？

::: tip 写作原则
能够运行的示例交给自动化验证；不能自动验证的观察，明确写出环境和日期。
:::
