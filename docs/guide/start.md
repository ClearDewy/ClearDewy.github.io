# 使用这个知识库

这个站点是面向自己的长期知识库：保留经过整理、验证、未来还会复用的知识，不以更新频率或文章数量为目标。

## 内容组织

- [智能算法](/ai/)：传统算法与模型、深度学习、LLM、Agent、训练、推理和 Harness 工程。
- [系统工程](/systems/)：操作系统、网络、数据库、分布式系统、软件架构和工程可靠性。
- [嵌入式](/embedded/)：电子基础、MCU/SoC、RTOS、驱动、通信协议、PCB 和机器人。

Python、C++、Linux 等属于横跨专栏的工具或技术标签，不单独成为一级专栏。新增文章应先在对应专栏的知识地图中找到位置，再进入文章流。

需要解释算法过程、系统状态或硬件时序时，可以使用站点内置的[交互式知识组件](/guide/interactive-components)。

## 一篇笔记应当包含什么

尽量回答四个问题：

1. 要解决什么问题？
2. 结论是什么？
3. 结论怎样得到或验证？
4. 哪些条件变化后，结论可能失效？

::: tip 写作原则
能够运行的示例交给自动化验证；不能自动验证的观察，明确写出环境和日期。
:::
