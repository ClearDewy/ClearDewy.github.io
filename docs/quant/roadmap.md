# 量化研究知识地图

## 市场、收益与统计基础

- 市场结构、资产与交易制度
- 收益率、复利、基准与风险调整
- 概率、统计推断与多重检验
- 经济机制、支付方与失效条件

## 数据、时间与研究总体

- As-of、Point-in-Time 与数据修订
- 证券身份、上市退市与历史总体
- 存活偏差、前视偏差与泄漏
- 数据资格、缺失机制、血缘与快照

## 因子与特征工程

- 价值、质量、动量、波动与反转
- 去极值、标准化、中性化与缺失处理
- IC、RankIC、ICIR 与分层单调性
- 衰减、换手、容量与因子相关性

## 模型、验证与证据

- 透明基线、线性模型与树模型
- Train、Validation、Test 与 Forward
- Walk-forward、OOS 与 Regime 稳定性
- 预注册、实验、Run、Evidence 与 Verdict

## 预测、风险与组合

- Alpha score、预测期限与不确定性
- 置信度、收缩与模型分歧
- 风险模型、压力测试与暴露约束
- 成本、冲击、容量与组合优化

## 执行、归因与生命周期

- 调仓、订单、成交与交易制度约束
- 模拟、影子运行与前向验证
- 市场、风格、Alpha、成本与执行归因
- Noise、Regime mismatch 与 Alpha death

## 量化系统工程

- 数据与研究的边界模型
- 可复现计算、不可变证据与血缘
- 任务编排、监控、权限与审计
- 安全失败、模拟交易与生产边界
