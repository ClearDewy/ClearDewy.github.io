# 量化研究

这个专栏关注一个金融想法怎样成为可信、可复现并且有资格进入实际系统的证据链，而不是收集漂亮的回测曲线或即时选股结论。

专栏本身保持完整：量化需要的统计模型、机器学习方法、数据工程和平台实现可以在这里结合金融问题重新讲解；[智能算法](/ai/)与[系统工程](/systems/)继续承担这些技术的通用主线。

## 研究主线

后续阶段不能替代前置阶段。数据可计算不代表因子有效，因子有效不代表形成 Alpha，历史收益也不等于可以获得的收益。

## 内容边界

- 市场机制、点时数据、因子研究、回测设计、风险成本、组合、执行和归因都可以在本专栏内完整展开。
- 通用模型原理和通用平台工程可以在这里按量化语境复述，但更深入的可迁移知识仍链接到对应基础专栏。
- 事实观察、研究证据、部署资格和交易建议必须明确区分；公开内容不构成投资建议。
- Nova 是项目状态、实现事实与研究证据的来源，博客沉淀稳定知识，不镜像正在变化的工作记录。
