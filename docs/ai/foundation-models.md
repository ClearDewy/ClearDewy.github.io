# 基础模型与生成模型

基础模型不是一种特定网络层，而是一种训练与复用范式：先在大规模宽分布数据上学习通用表示或生成能力，再通过提示、检索、微调或工具适配下游任务。

## 1. 文本如何成为学习目标

Tokenizer 把原始文本变为 token ID。Embedding 把离散 ID 映射为连续向量。自回归语言模型学习条件概率：

$$
p(x_1,\ldots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_{<t})
$$

训练时通常用当前位置预测下一个 token。这个目标提供了密集的自监督信号，但直接优化的是 token 概率，不是事实正确、意图遵循或安全。

## 2. 三类 Transformer 预训练范式

- Encoder-only：利用双向上下文学习表示，常用于理解、分类和抽取；
- Decoder-only：按前文生成后续 token，适合开放生成和上下文学习；
- Encoder–Decoder：编码输入、条件生成输出，适合翻译和显式转换任务。

架构选择由可访问的信息和目标因果结构决定，而不是简单的“新模型替代旧模型”。

## 3. 规模化意味着什么

模型性能受数据、参数、计算和优化共同影响。扩大单一维度可能造成欠训练、数据重复、优化不稳或服务成本失控。scaling law 是给定分布和实验范围内的经验关系，不是无限外推保证。

能力应拆成可观测任务来评估。“涌现”可能来自真实的非线性变化，也可能受到指标阈值、采样和评测分辨率影响。

## 4. Dense 与 MoE

Dense 模型每个 token 经过相同参数。MoE 用 router 为 token 选择少数专家，使总参数容量大于每 token 激活参数。它引入路由、负载均衡、通信和专家退化等新问题，不只是“更大的 FFN”。

## 5. 生成模型家族

| 家族 | 主要学习方式 | 典型特点 |
| --- | --- | --- |
| 自回归模型 | 按顺序预测下一个元素 | 生成自然、推理串行 |
| VAE | 潜变量概率模型与变分下界 | 潜空间连续、目标有近似 |
| GAN | 生成器与判别器对抗 | 样本锐利、训练不稳定 |
| 扩散模型 | 学习逐步去噪 | 训练稳定、采样多步 |

它们不是同一问题的 API 变体；概率分解、训练信号和采样过程不同。

## 6. 多模态模型

视觉、文本、音频可以通过共同表示空间、投影器、交叉注意力或统一 token 序列连接。需要分别评估感知、对齐、语言先验和生成，不能用一条看似合理的描述证明模型真正读取了输入模态。

## 7. 上下文中的能力

Prompt、few-shot 示例和 chain-of-thought 会改变条件输入，进而改变生成分布，但不会永久更新参数。需要区分：

- 参数中学习到的能力；
- 上下文提供的信息；
- 外部检索与工具返回的证据；
- 采样偶然得到的正确输出。

这一区分是后续微调、RAG 和 Agent 设计的基础。

## 8. 本章实践

对同一任务分别使用零样本、少样本、检索增强和小规模微调；固定评测集，对比质量、成本、延迟和失败模式。结论应说明改进来自哪里，而不只列模型名称。
