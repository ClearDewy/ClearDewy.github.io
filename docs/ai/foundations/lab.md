# 基础计算实验

## 目标与命题

验证三件事：矩阵乘法结果来自行列乘加；拆头前后元素数不变；解析梯度与中心有限差分一致。

## 环境与输入

- Python 3.10 或更高版本；不依赖第三方包；
- 固定矩阵 `A=[[1,2,3],[4,5,6]]`、`B=[[7,8],[9,10],[11,12]]`；
- 固定标量模型 `x=2,y=6,w=1`。

仓库内的可执行版本位于 `examples/python/ai_core_examples.py`。运行：

```bash
python examples/python/ai_core_examples.py
```

## 步骤与判断条件

1. 实现三层循环矩阵乘法，断言结果为 `[[58,64],[139,154]]`。
2. 断言 `2×4×8 == 2×4×2×4`，并打印拆头前后 shape。
3. 计算解析梯度和中心有限差分，断言差小于 `1e-6`。
4. 执行一次 `η=0.1` 的更新，断言 loss 从 `16` 降至约 `0.64`。

## 常见失败

- `IndexError`：检查 `B` 的行数是否等于 `A` 的列数。
- 有限差分不一致：确认使用中心差分且 `eps` 没有大到失真或小到被浮点舍入淹没。
- 更新后 loss 增大：先检查梯度符号，再减小学习率。
- `python` 命令不存在：改用系统实际 Python 3 启动器；不要改变脚本内容掩盖环境问题。
