# 智能算法

这个专栏关注智能系统从原理到落地的完整链路，不把模型、训练和应用工程割裂开来。

## 学习主线

```text
数学与算法基础
  → 传统模型与深度学习
  → 大语言模型
  → 数据、训练与对齐
  → 推理与模型服务
  → Agent 与 Harness
  → 评测、安全与可观测性
```

## 内容边界

- 模型原理、训练、推理以及 AI 专属基础设施归入本专栏。
- Agent 的上下文、工具、记忆、工作流、权限和评测属于 Harness 工程。
- 通用数据库、分布式系统和云基础设施归入[系统工程](/systems/)。
- 在设备侧运行模型、传感器融合和机器人控制与[嵌入式](/embedded/)交叉，通过标签连接。
