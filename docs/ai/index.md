# 智能算法

这个专题研究一个完整问题：**机器怎样从数据中形成可验证的能力，并被构造成可靠的智能系统？**

内容不按热门模型名堆放，也不以 MiniMind 或某个框架的目录作为知识结构。主线从数学与学习问题出发，进入神经网络、Transformer 和基础模型，再连接数据、训练、推理、评测、安全与 Agent 系统。具体项目只负责提供可运行的观察和实战证据。

## 阅读方式

- 第一次学习按 `0 → 1 → 2 → 3 → 4` 建立模型主线，同时从第 5、6 章学习最基本的实验和评测方法。
- 开始一个项目时按 `问题 → 数据 → 模型 → 训练 → 评测 → 推理 → 反馈` 横向查阅。
- 只想理解 Agent 时也应先掌握 token、生成、工具协议和评测，避免把框架 API 当作原理。
- 遇到公式时先明确变量语义和 shape，再看推导；遇到代码时先追踪数据流和不变量，再看框架封装。
