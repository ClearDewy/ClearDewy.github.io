# 学习问题与经典机器学习

机器学习不是“选择一个更复杂的模型”，而是从有限样本中学习一个能在未见数据上工作的规则。本章建立以后研究深度学习和大模型仍然需要的实验语言。

## 1. 先定义学习问题

一个可学习问题至少包含：输入 $x$、目标 $y$、数据分布、模型 $f_\theta$、损失函数、评测指标和使用约束。训练最小化的是样本上的经验风险：

$$
\hat R(\theta)=\frac{1}{n}\sum_{i=1}^{n}L(f_\theta(x_i),y_i)
$$

真正关心的是未来数据上的期望风险。两者的差距就是为什么需要数据划分、正则化、误差分析和分布外测试。

## 2. 学习范式

- **监督学习**：有明确标签，典型任务是分类、回归和排序；
- **无监督学习**：从无标签数据发现结构，如聚类、降维和密度估计；
- **自监督学习**：从数据本身构造目标，如预测被遮盖或下一个 token；
- **半监督/弱监督**：组合少量可靠标签和大量不完全信号；
- **强化学习**：通过状态、行动、奖励和环境交互学习策略。

这些范式的区别首先在“学习信号从哪里来”，其次才是模型结构。

## 3. 模型家族与归纳偏置

| 模型 | 主要假设或偏置 | 适合观察什么 |
| --- | --- | --- |
| 线性/逻辑回归 | 目标与特征近似线性可分 | 可解释基线、概率分类 |
| kNN | 相近样本有相近目标 | 局部结构、距离度量影响 |
| 朴素贝叶斯 | 给定类别后特征条件独立 | 概率建模与强假设的价值 |
| 决策树 | 规则可由递归切分形成 | 非线性、特征交互 |
| 随机森林 | 多个去相关树降低方差 | bagging 与集成 |
| Boosting | 逐步修正残差或梯度 | 强表格数据基线 |
| SVM | 最大间隔与核方法 | 几何、正则化和非线性映射 |
| 聚类/PCA | 距离或低维结构有意义 | 无监督结构与表示压缩 |

学习模型时固定回答：它限制了什么函数？这个限制为什么可能帮助泛化？数据不满足假设时怎样失败？

## 4. 数据划分与泄漏

训练集用于拟合参数，验证集用于选择模型和超参数，测试集只用于最终无偏估计。时间、用户、设备或实体有关的数据不能随意随机打散；只要未来信息或同一实体的近似副本跨越边界，指标就可能失真。

## 5. 指标由决策目标决定

- 类别均衡且错误代价接近时可看 accuracy；
- 类别不均衡时结合 precision、recall、F1、PR-AUC；
- 需要概率决策时关注 log loss、Brier score 和 calibration；
- 回归结合 MAE、RMSE、分位数损失及业务尺度；
- 排序问题使用与顶部质量和位置有关的指标。

单一平均值会隐藏子群体、长尾和失败模式。评测结果必须带数据范围、基线和误差分类。

## 6. 偏差、方差与泛化

欠拟合通常表现为训练和验证都差；过拟合表现为训练好、验证差。但真实问题还包括标签噪声、分布漂移、特征缺失和指标错配。增加参数不是唯一解，更多或更干净的数据、合适的归纳偏置和更好的目标函数可能更重要。

## 7. 本章实践

选择一个小型表格数据问题，依次完成：常数基线、线性模型、树模型和 boosting；固定数据划分，对比指标、训练时间和错误样本。最终报告模型为什么改善，以及证据仍不能支持哪些结论。
