# 1. 机器学习与泛化评估

这一章暂时不教复杂算法，只解决一个更基础的问题：

> 模型在已经见过的数据上表现很好，能不能说明它真的学会了？

答案是不能。它可能只是记住了训练样本，使用了预测时根本拿不到的信息，或者在一个不合适的分数上看起来很好。

## 把机器学习看成学习与考试

| 阶段 | 学生类比 | 模型在做什么 |
| --- | --- | --- |
| 训练集 | 带答案的练习册 | 根据样本和答案调整参数 |
| 验证集 | 模拟考试 | 选择模型、配置和判断阈值 |
| 测试集 | 最终闭卷考试 | 检查面对未见数据是否仍然有效 |
| 上线数据 | 真实工作 | 面对可能变化的新环境 |

如果把正式考试题提前放进练习册，最后的高分就没有意义。机器学习里把这种情况称为**数据泄漏**。

## 一个十秒钟能看懂的反例

要在用户付款时预测这笔交易以后会不会退款。模型使用了“退款完成时间”作为输入，测试准确率达到 99.8%。

这个模型不是厉害，而是偷看了未来：付款发生时，“退款完成时间”还不存在。无论分数多高，它都不能用于真实预测。

这一章就是学习如何识别这种“分数很好、结论却不成立”的实验。

## 只需要掌握三件事

1. **题目是什么**：模型在什么时候、根据哪些当时可见的信息、预测什么结果？
2. **怎样闭卷考试**：训练、调参和最终测试的数据怎样隔离，避免未来或重复样本泄漏？
3. **怎样算分**：分数是否对应真实代价，有没有被多数类、平均值或少数异常样本掩盖？

## 为什么先学这个

后面的神经网络、Transformer 和大模型都只能优化我们提供的数据与目标。若题目、数据或考试方式本身有问题，更复杂的模型只会更熟练地利用问题。

本章过关标准不是背算法名，而是能看着一份实验报告回答：模型何时做预测？当时能看到什么？与什么基线比较？在哪些未见数据上测过？这个分数代表什么，又没有证明什么？
