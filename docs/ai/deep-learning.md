# 神经网络与表示学习

经典机器学习常由人先设计特征，神经网络则把“怎样表示输入”也纳入学习。深度的价值不只是层数多，而是把复杂函数组织成可复用的分层变换。

## 1. 从线性层到 MLP

单个线性层的复合仍然是线性函数，因此需要激活函数引入非线性：

$$
h = \phi(xW_1+b_1), \qquad y=hW_2+b_2
$$

ReLU、GELU、SiLU 等激活函数影响梯度、稀疏性和计算。宽度控制每层可表示的特征数量，深度提供逐层组合。

## 2. 反向传播与可训练性

反向传播是链式法则在计算图上的高效复用。真正的难点是让信号能稳定穿过很多层：初始化控制前向/反向尺度，归一化控制分布，残差连接提供短梯度路径，合适的优化器和学习率控制更新。

需要持续观察激活、梯度、参数更新比、训练/验证曲线，而不是只看最终 loss。

## 3. CNN 的归纳偏置

卷积通过局部连接和权重共享假设“局部模式有意义，并可在不同位置重复出现”。感受野随层数扩大，低层可学习边缘，高层组合为更复杂模式。池化或步幅带来空间压缩，也可能损失位置信息。

## 4. RNN 与序列状态

RNN 用隐藏状态递归汇总历史：

$$
h_t=f(x_t,h_{t-1})
$$

它天然表达顺序，但时间步必须串行，长序列还会遇到梯度消失/爆炸和信息瓶颈。LSTM/GRU 通过门控改善记忆，却没有消除串行计算。这些限制推动了注意力和 Transformer。

## 5. 表示学习的共同问题

- **Embedding**：把离散对象映射到连续空间；
- **自编码器**：通过重建学习压缩表示；
- **对比学习**：拉近相关样本、推远不相关样本；
- **迁移学习**：复用预训练表示，只适配新任务；
- **多模态对齐**：让不同模态的表示具有可比较关系。

表示的几何性质只在特定训练目标和数据条件下成立，二维降维图不能单独证明语义已经被模型理解。

## 6. 现代网络构件

- normalization：LayerNorm、RMSNorm、BatchNorm 的归一化轴和使用场景；
- residual：维持信息和梯度通路；
- dropout、weight decay、数据增强：不同层面的正则化；
- gating：控制信息或专家路径；
- normalization placement：Pre-Norm 与 Post-Norm 的训练稳定性；
- initialization：保持各层激活和梯度的合理尺度。

## 7. 计算与资源

区分参数内存、激活内存、梯度和优化器状态；区分训练 FLOPs 与推理延迟。batch、分辨率、序列长度、宽度和深度影响不同。任何模型对比都应同时报告质量与资源。

## 8. 本章实践

1. 手写两层 MLP 和训练循环，在单 batch 上过拟合；
2. 记录无残差/有残差、不同初始化下的梯度；
3. 用小图像任务对比 MLP 与 CNN，解释归纳偏置；
4. 用短序列任务观察 RNN 的状态和串行限制；
5. 再进入[序列、注意力与 Transformer](/ai/transformers)。
