# 智能算法知识地图

## 数学与算法基础

- 概率统计、线性代数、微积分与数值计算
- 数据结构、经典算法、优化方法与复杂度分析
- 实验设计、误差分析与可复现计算

## 传统模型

- 线性模型、树模型、集成学习与概率模型
- 聚类、降维、异常检测与时间序列
- 特征工程、模型选择和解释方法

## 深度学习与大语言模型

- 神经网络基础、优化器与正则化
- CNN、RNN、Transformer 与多模态架构
- Tokenization、预训练、指令微调与对齐

## 数据与模型训练

- 数据采集、清洗、标注、版本和质量控制
- 训练循环、分布式训练、混合精度与检查点
- Fine-tuning、PEFT、蒸馏和实验追踪

## 推理与模型服务

- 推理图、量化、剪枝、缓存与批处理
- Serving、路由、并发、延迟和吞吐
- 成本估算、容量规划与故障降级

## Agent 与 Harness 工程

- Prompt、上下文管理、结构化输出与 Tool Calling
- Memory、RAG、状态机、工作流和多 Agent 协作
- 权限、沙箱、人工审批、失败恢复和任务调度
- Evals、Tracing、日志、成本与回归测试

## 评测、安全与应用

- 离线评测、在线评测、基准集与误差分类
- 幻觉、提示注入、数据泄漏与模型安全
- 搜索、推荐、代码智能、研究助手与垂直应用
