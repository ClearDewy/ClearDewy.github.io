# 嵌入式

这个专栏覆盖从电路和芯片到固件与完整设备的实现过程，把软件行为放回真实的电源、时序、接口和物理约束中理解。

## 学习主线

嵌入式系统处在持续的物理闭环中：供电和传感器形成输入，处理器与软件作出决策，执行器改变环境，新的状态再次被感知。

## 内容边界

- 芯片、外设、驱动、固件、电路、PCB 和设备集成归入本专栏。
- 与设备无关的操作系统、网络和分布式基础归入[系统工程](/systems/)。
- 模型训练和通用 Agent 工程归入[智能算法](/ai/)，端侧推理与传感器应用在这里记录实现。
