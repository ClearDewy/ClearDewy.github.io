# 电路、信号与测量速查

## 适用范围

适用于第 0 章的低压直流、理想串联回路和基础采样模型，验证日期为 2026-09-05。不覆盖市电安全、交流相位、半导体完整 I–V 模型和高频传输线。

## 量、单位与含义

| 量 | 符号 | 单位 | 含义 |
| --- | --- | --- | --- |
| 电压 | `V` | 伏特 V | 两点之间每单位电荷的能量差 |
| 电流 | `I` | 安培 A | 单位时间通过的电荷量 |
| 电阻 | `R` | 欧姆 Ω | 在线性模型中电压与电流之比 |
| 功率 | `P` | 瓦特 W | 单位时间转换的能量 |
| 电荷 | `Q` | 库仑 C | 电量 |
| 频率 | `f` | 赫兹 Hz | 每秒重复次数 |

```text
1 A = 1000 mA        1 mA = 1000 μA
1 kΩ = 1000 Ω        1 MΩ = 1000 kΩ
1 W = 1000 mW        1 ms = 0.001 s
```

## 核心公式

$$V=IR$$

$$P=VI=I^2R=\frac{V^2}{R}$$

$$I_{LED}\approx\frac{V_S-V_F}{R}$$

$$ADC_{code}=\operatorname{round}\left(\frac{V_{in}}{V_{ref}}(2^N-1)\right)$$

使用公式前先声明条件：欧姆定律直接适用于线性电阻；固定 `V_F` 只是 LED 的局部教学近似；ADC 公式是假设理想、单极性、无误差的模型。

## 仪表选择

| 要回答的问题 | 工具 | 接法/特点 |
| --- | --- | --- |
| 两点电压差是多少 | 万用表电压挡 | 并联，明确黑表笔参考点 |
| 一条支路流过多少电流 | 万用表电流挡 | 断开支路后串联，先选安全量程 |
| 电压怎样随时间变化 | 示波器 | 探头与参考地，观察幅度、边沿、噪声 |
| 数字边沿和协议时序是什么 | 逻辑分析仪 | 阈值判定，多通道长时间捕获 |
| 代码执行到哪里 | 调试器 | 断点、寄存器、内存；不能替代物理测量 |

## 不变量与默认值

- 电压永远是两个点之差；
- 稳态串联支路各处电流相同；
- 任意闭合回路的电压升降代数和为零；
- 数字输入按范围而非单点解释高低；未定义区不是第三个稳定逻辑值；
- ADC 输入必须满足允许范围、源阻抗和采样时间约束；
- 仪表接入会加载电路，只有理想模型才完全不影响被测对象。

1. 电源电压、极性和最大电流是否正确？
2. 电源地与信号参考地怎样连接？
3. 每个引脚允许范围和复位默认状态是什么？
4. 负载的最大电流、功率和反向能量由谁承担？
5. 第一次上电是否有限流、温升观察和可安全断电手段？

## 常见错误

- 电流挡并接电源；
- 示波器接地夹接到非隔离高侧节点；
- 把绝对最大额定值当作推荐工作值；
- 忽略 `mA/A`、`kΩ/Ω` 的千倍换算；
- 只看软件日志，不测供电、引脚和时序；
- 只用典型参数，不检查容差、温度和故障条件。
