# 虚拟万用表与采样实验

## 实验目标与命题

使用两套确定性演示验证：

1. 串联支路各处电流相同；
2. 电压表极性改变只改变读数符号，不改变原电路；
3. 增大串联电阻会降低电流，但功率变化必须结合约束判断；
4. ADC 位数改变量化网格，采样点数改变时间观察，两者不是同一件事。

## 环境与固定输入

| 项目 | 值 |
| --- | --- |
| 环境 | 支持 JavaScript 和 SVG 的现代浏览器 |
| 外部硬件 | 不需要 |
| 电路基线 | 3.3 V、330 Ω、LED 压降 2.0 V |
| 采样基线 | Vin 1.27 V、Vref 3.3 V、10 bit |
| 验证日期 | 2026-09-05 |

这是假设理想导线、理想电源和固定 LED 压降的教学模型，不能代替真实器件测试。

## 实验一：先预测，再测量

开始前写下基线电流和电阻功率，然后操作：

<ClientOnly><CircuitMeasurementDemo /></ClientOnly>

步骤：

1. 保持基线，选择“测电阻压降”，确认约为 `1.30 V`；
2. 切换为“测 LED 压降”，确认约为 `2.00 V`；
3. 切换为“测支路电流”，确认约为 `3.94 mA`；
4. 把电阻改为 `660 Ω`，记录电流和功率；
5. 交换电压表表笔，确认只有符号改变；
6. 断开回路，确认电流归零而电源两端仍可存在电压。

### 判断条件

基线理论值：

```text
VR = 3.3 - 2.0 = 1.3 V
I  = 1.3 / 330 = 3.94 mA
PR = 1.3 × 3.94 mA = 5.12 mW
```

电阻加倍后电流和电阻功率在该固定电压模型下约减半。若结果不符，先检查单位、回路开关、LED 压降是否小于电源，以及当前仪表模式。

## 实验二：把“电平”和“数值”分开

<ClientOnly><SignalSamplingDemo /></ClientOnly>

步骤：

1. 将 `Vin` 设为 `0.4 V`、`1.4 V`、`2.8 V`，分别记录逻辑分类；
2. 在 `Vin=1.27 V`、`Vref=3.3 V` 时比较 8、10、12 位 ADC 码；
3. 保持 10 位，将 `Vref` 改为 2.5 V，先预测再观察；
4. 分别使用 5、9、17 个采样点，观察采样是否击中连续波形的峰值；
5. 说明为什么增加 ADC 位数不能补回两次采样之间遗漏的变化。

### 判断条件

`1.4 V` 落在基线阈值的未定义区；`1.27 V` 在 10 位、3.3 V 参考下应得到约 `394`。若输入超出 `0–Vref`，演示会钳位输出码并显示越界提示，而不是假装 ADC 可以表示更高电压。

## 实际观察与解释

基线已在 Chrome 兼容浏览器中复核：回路给出 `3.94 mA / 5.12 mW`，ADC 给出码值 `394`。修改参数后所有派生值同步重算，重置会恢复上述基线。

这些结果证明组件的理想模型内部一致；没有证明真实 LED 压降、ADC 精度或探头接法正确。

## 常见失败与排查

| 现象 | 首先检查 | 原因 |
| --- | --- | --- |
| 电流始终为 0 | 回路是否断开；`Vs > Vf` | 没有正向压差或闭合路径 |
| 电压读数为负 | 表笔极性 | 参考方向相反 |
| ADC 一直满量程 | `Vin` 是否超过 `Vref` | 输入越界后被钳位 |
| 采样点看不出峰值 | 采样数量与相位 | 离散时刻没有击中峰值 |
| 修改后自动播放停止 | 这是预期行为 | 原位编辑优先保留当前因果状态 |

## 复现、清理与下一步

点击组件内“恢复基线”即可清理全部修改；实验不上传或持久化参数。记录至少包含修改前预测、修改后读数和一句因果解释。
