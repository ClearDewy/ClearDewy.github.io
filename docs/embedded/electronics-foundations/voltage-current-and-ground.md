# 电压、电流与参考地怎样组成闭合回路

## 先看问题

“这根线是 3.3 V”缺少一个条件：**相对哪个参考点是 3.3 V？** “电流从电源出来”也不完整：没有返回电源的闭合路径，持续电流就无法形成。

本页只解决直流稳态下的节点、电压差、支路和测量接法，不讨论电子真实漂移方向或高频寄生参数。

## 固定电路

```text
节点 A             节点 B              节点 G
 3.3 V ───── R ───── 约 2.0 V LED ───── GND
          同一串联支路，电流 I 沿整条路径流动
```

这里把电源负端选为 `GND`，约定它是 `0 V`。因此“A 点是 3.3 V”实际是：

$$V_A - V_G = 3.3\ \text{V}$$

电压是两个点之间每单位电荷的能量差，不是装在一根线里的物质。同一节点上的理想导线近似等电位；穿过器件后可能产生电压降。

## 电流必须有闭合路径

电流描述电荷流率：

$$I = \frac{\Delta Q}{\Delta t}$$

工程上使用传统电流方向，从较高电势经负载流向较低电势。固定案例只有一条串联支路，所以流过电阻和 LED 的电流相等。若 LED 反接、导线断开或电源没有返回路径，理想化直流电流为零。

::: warning GND 不是宇宙统一的零伏
GND 只是当前电路选定的参考与回流节点。两台独立供电设备可能没有共同参考；直接连接信号线前必须确认参考地和允许的共模范围。
:::

## 两种仪表为何接法相反

### 测电压：跨在两个点之间

电压表比较红、黑表笔两端的电势差，因此与被测对象**并联**。理想电压表内阻无穷大，希望尽量不从原电路分走电流。

```text
A ─── R ─── B
      │     │
      └─ V ─┘
```

### 测电流：让支路电流经过仪表

电流表必须插入目标支路，与负载**串联**。理想电流表内阻接近零，希望不明显改变原支路。

```text
A ─── A表 ─── R ─── LED ─── GND
```

如果把电流挡仪表直接并在电源两端，相当于用很小电阻短接电源，可能烧保险丝、损坏仪表或电源。这不是“读数不准”，而是危险接法。

## 常见误解

- **“GND 里没有电压，所以没有电流。”** GND 是参考节点，仍可以承担回流。
- **“电阻先用掉一部分电流，LED 再用剩下的。”** 串联稳态支路各处电流相同，器件分配的是电压降和功率。
- **“表笔碰到一根线就能测电压。”** 电压需要两个测点；黑表笔所接参考决定读数。
- **“软件读到高电平就证明供电正常。”** 输入保护、悬空和回灌都可能制造假象，必须结合真实电压与连接条件。

## 小结与自测

电压属于两点，电流属于路径，GND 属于参考与回流约定。电压表并联，电流表串联。

自测：A 点为 3.3 V、B 点为 2.0 V，黑表笔接 B、红表笔接 A，读数是多少？交换表笔后呢？

<details><summary>答案</summary>

先读 `3.3 - 2.0 = 1.3 V`；交换后为 `-1.3 V`。负号表示测量极性与原约定相反。
</details>
