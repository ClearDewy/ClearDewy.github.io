# 嵌入式知识地图

## 电子与硬件基础

- 电压、电流、阻抗、功率、信号完整性与电源完整性
- 模拟电路、数字逻辑、常用器件与数据手册阅读
- 原理图、PCB、供电、保护、EMC 与热设计

## 处理器与嵌入式软件

- MCU、MPU、SoC、体系结构与存储层次
- 启动流程、链接脚本、中断、定时器和低功耗
- 裸机程序、HAL、BSP、驱动与固件升级

## RTOS 与系统集成

- 任务调度、同步、通信、内存管理与实时性
- 启动、故障恢复、Watchdog 和状态管理
- Linux 嵌入式、设备树、内核驱动与用户态服务

## 接口与通信

- GPIO、ADC、PWM、UART、I²C、SPI 与 CAN
- USB、以太网、Wi-Fi、Bluetooth 与现场总线
- 协议设计、时序分析、抓包和互操作测试

## 调试、测试与可靠性

- 万用表、示波器、逻辑分析仪和调试器
- 单元测试、硬件在环、产测、日志与故障注入
- 功耗、性能、环境适应性和安全边界

## 机器人与边缘智能

- 传感器、执行器、运动控制与电源系统
- 定位、感知、融合、控制和设备通信
- 模型压缩、端侧推理与软硬件协同优化
