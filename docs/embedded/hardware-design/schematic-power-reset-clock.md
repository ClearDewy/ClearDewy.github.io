# 原理图、电源、复位与时钟怎样形成可启动硬件

## 从负载预算画电源树

```text
输入源 → 保护/滤波 → 稳压器 → 3.3 V rail
                            ├─ MCU
                            ├─ 传感器
                            └─ 通信与指示灯
```

稳压器选择至少需要输入范围、输出精度、持续与峰值电流、压差、效率、静态电流、瞬态响应、热阻和稳定性所需电容。把各器件典型电流相加不是最坏预算；无线发射、LED、电机启动和 Flash 操作可能产生峰值。

直接修改各负载峰值和稳压器额定电流，观察余量与近似耗散。演示不替代数据手册降额和热仿真。

## 去耦解决局部瞬态回路

去耦电容应靠近电源引脚，让快速电流在芯片—电容的小回路内流动；大容量电容支撑较慢负载变化。电容标称值还受偏压、温度、容差和封装寄生影响，不能只看丝印数值。

## 复位与启动配置必须有确定默认值

复位脚需要满足电平、脉宽、上升时间和噪声要求；启动模式脚不能悬空。调试接口、量产测试点和恢复模式应在原理图阶段预留，否则固件失效后可能无法救砖。

## 时钟是一条模拟网络

外部晶振需要匹配负载电容、布局回路和器件建议；内部振荡器更简单但精度和温漂可能不满足 USB、精确 UART 或无线协议。时钟“能振”不代表频率、幅度和启动时间都合格。

## 常见误解

- 直接复制评估板，不核对自己的输入、负载和布局；
- 去耦电容值正确就任意摆放；
- MCU 平均电流低于稳压器额定值就忽略峰值和热；
- 用普通示波器探头直接接晶振节点，探头电容改变振荡；
- 不预留调试、复位、启动和电流测量入口。
