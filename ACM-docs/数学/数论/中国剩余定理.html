                                  # 中国剩余定理

                                  # CRT

                                  中国剩余定理 (Chinese Remainder Theorem, CRT) 可求解如下形式的一元线性同余方程组（其中 n1,n2,n3,⋯ ,nkn_1,n_2,n_3, \cdots ,n_kn1​,n2​,n3​,⋯,nk​ 两两互质）：

                                  {x≡a1(modn1)x≡a2(modn2)⋮x≡ak(modnk) \begin{cases} x \equiv a_1 \pmod {n_1} \\ x \equiv a_2 \pmod {n_2} \\ \quad \vdots \\ x \equiv a_k \pmod {n_k} \\ \end{cases} ⎩⎨⎧​x≡a1​(modn1​)x≡a2​(modn2​)⋮x≡ak​(modnk​)​

                                  # 算法流程:

                                  1. 计算所有模数的积 nnn；
                                  2. 对于第iii个方程：

                                  ​ a.计算 mi=nnim_i = \frac{n}{n_i}mi​=ni​n​

                                  ​ b.计算mim_imi​在模nin_ini​意义下的 逆元open in new window mi−1m_i^{-1}mi−1​；

                                  ​ c.计算 ci=mimi−1c_i = m_i m_i^{-1}ci​=mi​mi−1​（不要对nin_ini​取模）。

                                  1. 方程组的唯一解为：x=∑i=1kaici((modn))x=\sum_{i=1}^k a_i c_i (\pmod n)x=∑i=1k​ai​ci​((modn)) 。

                                  # 代码实现:

                                  ll CRT(int k, ll *a, ll *r)
{
    ll n = 1, ans = 0;
    for (int i = 1; i <= k; i++)
        n = n * r[i];
    for (int i = 1; i <= k; i++)
    {
        ll m = n / r[i], b, y;
        exgcd(m, r[i], b, y); // b * m mod r[i] = 1
        ans = (ans + a[i] * m * b % n) % n;
    }
    return (ans % n + n) % n;
}

                                  # EX_CRT

                                  设两个方程分别是:

                                  {x≡a1(modm1)x≡a2(modm2) \begin{cases} x &\equiv a_1 \pmod {m_1} \\x &\equiv a_2 \pmod {m_2} \end{cases} {xx​≡a1​(modm1​)≡a2​(modm2​)​

                                  x=m1p+a1=m2q+a2 x=m_1p+a_1=m_2q+a_2 x=m1​p+a1​=m2​q+a2​

                                  m1p−m2q=a2−a1 m_1p-m_2q=a_2-a_1 m1​p−m2​q=a2​−a1​
