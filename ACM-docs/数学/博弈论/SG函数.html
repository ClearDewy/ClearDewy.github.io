        # 有向图游戏与 SG 函数

        定义 mexmexmex 函数的值为不属于集合 中的最小非负整数，即：

        mex⁡(S)=min⁡{x}(x∉S,x∈N) \operatorname{mex}(S)=\min\{x\} \quad (x \notin S,x\in N) mex(S)=min{x}(x∈/S,x∈N)

        例如mex⁡({0,2,4})=1\operatorname{mex}(\{0,2,4\})=1mex({0,2,4})=1 ，mex⁡({1,2})=0\operatorname{mex}(\{1,2\})=0mex({1,2})=0。

        对于状态 xxx 和它的所有 kkk 个后继状态 y1,y2,…,yky_1,y_2,\dots ,y_ky1​,y2​,…,yk​ ，定义 SGSGSG 函数：

        SG⁡(x)=mex⁡{SG⁡(y1),SG⁡(y2),…,SG⁡(yk)} \operatorname{SG}(x)=\operatorname{mex}\{\operatorname{SG}(y_1),\operatorname{SG}(y_2),\dots,\operatorname{SG}(y_k) \} SG(x)=mex{SG(y1​),SG(y2​),…,SG(yk​)}

        而对于由 nnn 个有向图游戏组成的组合游戏，设它们的起点分别为 s1,s2,…,sns_1,s_2,\dots,s_ns1​,s2​,…,sn​ ，则有定理：当且仅当 SG⁡(s1)⊕SG⁡(s2)⊕⋯⊕SG⁡(sk)≠0\operatorname{SG}(s_1) \oplus \operatorname{SG}(s_2) \oplus \dots \oplus \operatorname{SG}(s_k) \neq 0SG(s1​)⊕SG(s2​)⊕⋯⊕SG(sk​)=0 时，这个游戏是先手必胜的。同时，这是这一个组合游戏的游戏状态 xxx 的 SG 值。
