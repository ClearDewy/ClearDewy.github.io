# 多表查询

```sql
SELECT * FROM 表1 , 表2 WHERE 表1列 = 表2列;
```

1. 内连接

```sql
-- 隐式
SELECT 字段列表 FROM 表1，表2…… WHERE ;
-- 显示
SELECT 字段列表 FROM 表1 [INNER] JOIN 表2 ON 条件;
```

2. 外连接

```sql
-- 左外连接
SELECT 字段列表 FROM 表1 LEFT [OUTER] JOIN 表2 ON 条件;
-- 右外连接
SELECT 字段列表 FROM 表1 RIGHT [OUTER] JOIN 表2 ON 条件;
```
