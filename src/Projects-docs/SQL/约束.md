# 约束

| 约束名称 | 描述                                                       | 关键字      |
| -------- | ---------------------------------------------------------- | ----------- |
| 非空约束 | 保证列中所有数据不能有NULL值                               | NOT NULL    |
| 唯一约束 | 保证列中所有数据各不相同                                   | UNIQUE      |
| 主键约束 | 主键时一行数据的唯一标识，要求非空且唯一                   | PRIMARY KEY |
| 检查约束 | 保证列中的值满足某一条件                                   | CHECK       |
| 默认约束 | 保存数据时，未指定值则采用默认值                           | DEFAULT     |
| 外键约束 | 外键用来让两个表数据之间建立链接，保证数据的一致性和完整性 | FOREIGN KEY |

## 约束

```sql
CREATE TABLE 表名(
	字段名1 数据类型1 约束名称,
    字段名2 数据类型2 约束名称,
    ……
    字段名3 数据类型3 约束名称
);
```

## 外键约束

```sql
-- 创建表时添加
CREATE TABLE 表名(
	字段名 数据类型,
    ……
	[CONSTRAINT] [外键名称] FOREIGN KET(外键列名) REFERENCES 主表(主表列名)
);

-- 建表后添加
ALTER TABLE 表名 ADD CONSTRAINT 外键名称 FOREIGN KEY(外键列名) REFERENCES 主表(主表列名);

-- 删除约束
ALTER TABLE 表名 DROP FOREIGN KEY 外键列名;

-- 外键级联
ON DELETE CASCADE 级联删除
ON UPDATE CASCADE 级联更新
```
