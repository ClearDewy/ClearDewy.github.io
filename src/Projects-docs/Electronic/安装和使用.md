# 基本用法

```powershell
# 安装
npm install electron --save-dev

# 运行
npx electron .

# 打包
npm install electron-packager --save-dev
electron-packager ./ acm签到系统 --win --out ./outputs --icon=src/assets/favicon.ico
```

可写在$package.json$中简便运行

```json
package.json
{
    "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "electron:serve": "electron .",
    "packager": "electron-packager ./ acm签到系统 --win --out ./outputs --icon=src/assets/favicon.ico"
  },
}

//使用npm run dev等运行
```
