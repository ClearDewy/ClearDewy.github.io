# 注解

```java
@MapperScan("com/qingtuan/labelclocksystem/mapper")
//修饰Application主类，提供mapper路径

@RestController
//Controller类，定义路由访问的类

@RequestMapping("/api")
//设置路由访问的路径
//细分为@PostMapping等

@ResponseBody
//返回json对象的body区

@Autowired
//修饰数据成员为bean

@Data
//修饰类，给类的数据成员提供getter,setter方法

@AllArgsConstructor
//修饰类，给类提供全部参数的构造函数

@NoArgsConstructor
//修饰类，给类提供无参的构造函数
```
