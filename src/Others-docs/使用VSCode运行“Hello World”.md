    **如果是不理解的地方建议照做**

    ## 1. 安装VSCode

    进入[VSCode官网](https://code.visualstudio.com/)，点击下载安装程序，然后安装；

    ![image-20220904232534123](https://raw.githubusercontent.com/Qingqingtuan/TyporaImg/main/img/202210161827236.png)

    ## 2. 下载插件和MinGW

    a. 打开VSCode应用，下载Chinese，c++，Code Runner，Competitive Programming Helper (cph)

    ![12315](https://raw.githubusercontent.com/Qingqingtuan/TyporaImg/main/img/202210161827436.png)

    

    b. 下载[Environment](https://share.weiyun.com/5jAA3Wck)压缩文件并解压，得到Code和MinGW两个文件

    将MinGW文件放在你觉得凉快的地方（bushi，例如D盘下新建Environment文件夹

    ![2](https://raw.githubusercontent.com/Qingqingtuan/TyporaImg/main/img/202210161828692.png)

    **配置环境变量：**

    右键“我的电脑”-->“属性”-->”高级系统设置“-->”环境变量“

    ![3](https://raw.githubusercontent.com/Qingqingtuan/TyporaImg/main/img/202210161828790.png)

    ![4](https://raw.githubusercontent.com/Qingqingtuan/TyporaImg/main/img/202210161828443.png)

    # 3. 运行程序

    用VSCode打开解压出来的Code文件，新建.cpp文件，就可以开始愉快的编程啦！

    ![5](https://raw.githubusercontent.com/Qingqingtuan/TyporaImg/main/img/202210161829801.png)

    ”1“处右键新建文件，加上”.cpp“后缀

    ”2“.处右击RUN CODE运行程序，或者点击”3“处运行

    ”4“处为输出结果
