# 使用方法

在代码同级目录下新建`xk_user.json`和`xk_idList.json`文件分别存放账号密码和课程参数。格式如下

## xk.json

```json
{
  "username": "your_student_number",
  "password": "your_password",
  "data": [
    {
      "method": "handleTjxk",
      "jxbid": "20232024120110300081302",
      "glJxbid": ""
    },
    {
      "method": "handleTjxk",
      "jxbid": "20232024120110300191303",
      "glJxbid": ""
    }

  ]
}
```




## 参数说明

### 请求参数

-   请求地址:`http://xk.scuec.edu.cn/xsxk/xkOper.xk`

-   请求参数:

    ```json
    {
        "method": calssdata["method"],
        "jxbid": calssdata["jxbid"],
        "glJxbid": calssdata["glJxbid"],
    }
    ```

### $method$参数

| method                | 对应选课       | 所需参数                                        |
| :-------------------- | :------------- | :---------------------------------------------- |
| handleTjxk            | 推荐选课       | jxbid glJxbid                                   |
| handleBfakc           | 方案内选课     | jxbid glJxbid                                   |
| handleKzyxk           | 方案外选课     | jxbid glJxbid                                   |
| handleCxxk            | 重修选课       | jxbid glJxbid                                   |
| handleTykxk(暂未测试) | 体育选择选课   | jxbid(暂未测试)                                 |
| handleQxgxk           | 通识课程选修   | jxbid glJxbid xkzy (**注意：补选时不需要xkzy**) |
| handleCxcy            | 创新创业类选课 | jxbid                                           |

### glJxbid 的获取

#### 方法①

**适用于在选课未开始时，提前查看关联课信息**

分析一下 **获取关联课表格** 时的请求
> http://xk.scuec.edu.cn/xsxk/loadData.xk?method=getGljxb&jxbid=20202021220610003861801

- *http:///xk.scuec.edu.cn/xsxk/loadData.xk*
- *method=**getGljxb***
- *jxbid=**20202021220610003861801***
