# 经典博弈

## 巴什博弈（Bash Game）

>   一堆$n$个物品，两个人轮流从中取出$1~m$个，最后取光者胜（不能继续取的人输）。

同余定理：$n=k∗(m+1)+r$，先者拿走$r$个，那么后者无论拿走$1 m$个先者只要的数目使和为$m+1$，那么先手必赢。反之若$n=k∗(m+1)$，那么先手无论怎样都会输。

## 斐波那契博弈（Fibonacci Nim Game）

>一堆石子有$n$个，两人轮流取，先取者第一次可以去任意多个，但是不能取完，以后每次取的石子数不能超过上次取子数的2倍。取完者胜。

同样是一个规律：先手胜当且仅当n不是斐波那契数。

## 威佐夫博弈（Wythoff Game）

>有两堆各若干物品，两个人轮流从任意一堆中至少取出一个或者从两堆中取出同样多的物品，规定每次至少取一个，至多不限，最后取光者胜。

先求出差值，差值\*黄金分割比$==$最小值的话后手赢，否者先手赢。*（黄金分割比：$\frac{\sqrt5-1}{2}$）*

## 尼姆博弈（Nimm Game）

>   有n堆物品，两人轮流取，每次取某堆中不少于1个，最后取完者胜。

将每堆物品数异或和，结果为$0$先手必输，否则必胜
