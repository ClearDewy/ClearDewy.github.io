# 位运算

## 快速幂

```cpp
inline ll fp(ll x, ll y) {
	ll base = 1;
	while (y){
		if (y&1)base=base*x%mod;
		x =x*x%mod;
		y >>= 1;
	}
	return base;
}
```

## 快速乘

```cpp
ll mul(ll x,ll y,ll &mod){
    ll base = 0;
    while (y)
    {
        if (y&1)base = (base + x) % mod;
        x = (x << 1) % mod;
        y >>= 1;
    }
    return base;
}
```

## 2^k

- 判断一个数是不是2^k:`x&(x-1)==0?1:0;`
- 不大于x的最大2^k:[(证明)](https://blog.csdn.net/dreamispossible/article/details/91162847)

```cpp
//int 范围
int elog2(int x)
{
    x |= x >> 1;
    x |= x >> 2;
    x |= x >> 4;
    x |= x >> 8;
    x |= x >> 16;
    return (x + 1) >> 1;
}

//long long 范围
ll elog2(ll x) {
    x |= x >> 1;
    x |= x >> 2;
    x |= x >> 4;
    x |= x >> 8;
    x |= x >> 16;
    x |= x >> 32;
    return (x + 1) >> 1;
}
```
