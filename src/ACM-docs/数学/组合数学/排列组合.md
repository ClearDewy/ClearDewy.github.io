# 排列组合

## 基本公式

$$
\mathrm A_n^m = n(n-1)(n-2) \cdots (n-m+1) = \frac{n!}{(n - m)!} \\

\binom{n}{m}= \mathrm C_n^m = \frac{\mathrm A_n^m}{m!} = \frac{n!}{m!(n - m)!}
$$

```cpp
inline ll C(const int &x,const int &y) {		//y中选x个
    ll base = 1;
    if (x==0)return base;
    for (int i = y; i > y-x; i--)
    {
        base = base * i / (y - i + 1);
    }
    return base;
}
```

## 组合数性质 | 二项式推论

$$
\begin{aligned}
\binom{n}{m}&=\frac{n}{m} \binom{n-1}{m-1}\\
\binom{n}{m}&=\binom{n-1}{m}+\binom{n-1}{m-1}\\
\binom{n}{0}+\binom{n}{1}+\cdots +\binom{n}{n}&=2^n\\
\sum_{i=0}^n(-1)^i\binom{n}{i}&=[n=0]\\
\sum_{i=0}^m\binom{n}{i}\binom{m}{m-i}&=\binom{n+m}{m} \ (n\geq m)\\
\sum_{i=0}^ni\binom{n}{i}&=n2^{n-1}
\end{aligned}
$$
