# 中国剩余定理

## CRT

中国剩余定理 (Chinese Remainder Theorem, CRT) 可求解如下形式的一元线性同余方程组（其中 $n_1,n_2,n_3, \cdots ,n_k$ 两两互质）：
$$
\begin{cases} x \equiv a_1 \pmod {n_1} \\ x \equiv a_2 \pmod {n_2} \\ \quad  \vdots \\ x \equiv a_k \pmod {n_k} \\ \end{cases}
$$

### 算法流程:

1. 计算所有模数的积 $n$；
1. 对于第$i$个方程：

​		a.计算 $m_i = \frac{n}{n_i}$

​		b.计算$m_i$在模$n_i$意义下的 [逆元](https://oi-wiki.org/math/number-theory/inverse/) $m_i^{-1}$；

​		c.计算 $c_i = m_i m_i^{-1}$（**不要对$n_i$取模**）。

3. 方程组的唯一解为：$x=\sum_{i=1}^k a_i c_i (\pmod n)$ 。

### 代码实现:

```cpp
ll CRT(int k, vector<ll>& a, vector<ll>& r)
{
    ll n = 1, ans = 0;
    for (int i = 1; i <= k; i++)
        n = n * r[i];
    for (int i = 1; i <= k; i++)
    {
        ll m = n / r[i], b, y;
        exgcd(m, r[i], b, y); // b * m mod r[i] = 1
        b=b<0?b+r[i]:b;            // 求解 m 在 r[i] 下的逆元
        ans = (ans + a[i] * m % n * b % n) % n;
    }
    return (ans % n + n) % n;
}
```

## EX_CRT

设两个方程分别是:
$$
\begin{cases} x &\equiv a_1 \pmod {m_1} \\x &\equiv a_2 \pmod {m_2} \end{cases}
$$
转化为不定方程：
$$
x=m_1p+a_1=m_2q+a_2
$$
其中 $p,q$ 是整数，则有:
$$
m_1p-m_2q=a_2-a_1
$$
由裴蜀定理，当 $a_2 - a_1$ 不能被 $gcd(m_1,m_2)$ 整除时，无解；

其他情况下，可以通过扩展欧几里得算法解出来一组可行解 $(p,q)$;

则原来的两方程组成的模方程组的解为 :
$$
x \equiv b \pmod M
$$
其中 :
$$
b=m_1p+a_1,M=lcm(m_1,m_2)
$$
