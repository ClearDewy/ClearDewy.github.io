# 欧拉筛

欧拉筛也叫线性筛

```cpp
const int pri =1e6;
bitset<pri+5> visi;
int prime[pri+5],num = 0;

void get_prime() {
	for (int i = 2; i <= pri; i++)
	{
		if (!visi[i])prime[++num] = i;
		for (int j = 1; j <= num && i * prime[j] <= pri; j++)
		{
			visi[i * prime[j]] = 1;
			if (i % prime[j] == 0)break;
		}
	}
}
```
