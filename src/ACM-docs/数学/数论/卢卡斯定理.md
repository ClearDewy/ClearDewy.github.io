# 卢卡斯定理

## Lucas 定理

### 定义

对于质数$p$，有
$$
\binom{n}{m}\bmod p = \binom{\left\lfloor n/p \right\rfloor}{\left\lfloor m/p\right\rfloor}\cdot\binom{n\bmod p}{m\bmod p}\bmod p
$$

### 代码实现

```cpp
inline ll lucas(ll x,ll y){
    if(!y)return 1;
    return C(x%mod,y%mod)*lucas(x/mod,y/mod)%mod;
}
```
