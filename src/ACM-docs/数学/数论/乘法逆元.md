### 乘法逆元

## 费马小定理求逆元

```cpp
inline ll fp(ll x, ll y) {
	ll base = 1;
	while (y){
		if (y&1)base=base*x%mod;
		x =x*x%mod;
		y >>= 1;
	}
	return base;
}
ll getinv(const ll &x) {
	return fp(x, mod - 2);
}
```

## 扩展欧几里得

方程 $ax+by=c$与方程 $ax \equiv c \pmod b$是等价的，有整数解的充要条件为 $gcd(a,b)|c$

```cpp
inline void exgcd(ll a, ll b, ll& x, ll& y) {
	if (b == 0) {
		x = 1, y = 0;
		return;
	}
	exgcd(b, a % b, y, x);
	y -= a / b * x;
}

ll getinv(const ll& x) {
	ll p, q;
	exgcd(x, mod, p, q);
	return (p%mod+mod)%mod;
}
```

## 线性法求逆元

```cpp
const int N = 1e5 + 5;
ll inv[N] = { 0 };

void getinv(const ll& x) {
    inv[1] = 1;
    for (int i = 2; i <= x; i++) {
        inv[i] = (ll)(mod - mod / i) * inv[mod % i] % mod;
    }
}
```
