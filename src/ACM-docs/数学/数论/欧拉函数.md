# 欧拉函数

欧拉函数（Euler's totient function），即$\varphi(n)$，表示的是小于等于$n$和$n$互质的数的个数。

## 求单个数字的欧拉函数

```cpp
inline int phi(int x) {
    int ans = x;
    for (int i = 2; i <= x/i; i++)
        if (x % i == 0) {
            ans = ans / i * (i - 1);
            while (x % i == 0) 
                x /= i;
        }
    if (x > 1) ans = ans / x * (x - 1);
    return ans;
}
```

## 筛法求欧拉函数

```cpp
const int N = 1e5 + 5;
bitset<N+5>visi;
int phi[N+5] = { 0 };
int prime[N+5] = { 0 };
int cnt = 0;

void getphi() {
    int cnt = 0;
    visi[1] = 1;
    phi[1] = 1;
    for (int i = 2; i <= N; i++) {
        if (!visi[i]) {
            prime[++cnt] = i;
            phi[i] = i - 1;
        }
        for (int j = 1; j <= cnt && i * prime[j] <= N; j++) {
            visi[i * prime[j]] = 1;
            if (i % prime[j])
                phi[i * prime[j]] = phi[i] * phi[prime[j]];
            else {
                phi[i * prime[j]] = phi[i] * prime[j];
                break;
            }
        }
    }
}
```
