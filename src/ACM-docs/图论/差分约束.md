# 差分约束

## 概念

差分约束系统是下面这种形式的多远一次不等式组（ $y_1,y_2,\dots,y_m$ 已知）：
$$
\begin{cases}
x_{a_1}-x_{b_1}&\leq y_1\\
x_{a_2}-x_{b_2}&\leq y_2\\
\dots\\
x_{a_m}-x_{b_m}&\leq y_m\\
\end{cases}
$$
即 $n$ 个变量和 $m$ 个约束条件，求得一组解满足所有约束条件。

## 解法

约束条件 $x_i-x_j=y_k$ 可变形为 $x_i=y_k+x_j$ ，类似与单源最短路中三角形不等式 $dis[y]\leq dist[x]+z$ 。因此，我们将每个 $x$ 看作一个节点，对于每个约束条件 $x_i-x_j=y_k$ 从节点 $j$ 向节点 $i$ 连一条长度为 $y_k$ 的有向边。

注意到，如果 $\{a_1,a_2,\dots,a_n\}$ 是该差分约束系统的一组解，那么对于任意的常数 $d$ ，$\{a_1+d,a_2+d,\dots,a_n+d\}$ 显然也是该差分约束系统的一组解，因为这样做差后 ![d](data:image/gif;base64,R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7) 刚好被消掉。

设 $dis[0]=0$ 并向每一个点连一条权重为 0 边，跑单源最短路，若图中存在负环，则给定的差分约束系统无解，否则，$x_i=dist[i]$ 为该差分约束系统的一组解。

一般使用 Bellman–Ford 或队列优化的 Bellman–Ford（俗称 SPFA，在某些随机图跑得很快）判断图中是否存在负环，最坏时间复杂度为 $O(nm)$ 。
