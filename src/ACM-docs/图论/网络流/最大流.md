# 最大流

网络流中最常见的问题就是**网络最大流**。假定从源点流出的流量足够多，求能够流入汇点的最大流量。

## 解决方法

-   引入**反向边**。在建边的同时，在反方向建一条边权为0的边：*（使用链式前向星时，将边数初始化为$1$，这样$ent$^$1$即反边*

![v2-1c4016f73a2e94109fbb8769a1e88566_r](https://raw.githubusercontent.com/ClearDewy/TyporaImg/main/img/202303231420810.jpg)

-   选择1->2->3->4，但在扣除正向边的容量时，反向边要**加上**等量的容量。

![v2-f19ff404a0932ca1d6bdf713403142cf_1440w](https://raw.githubusercontent.com/ClearDewy/TyporaImg/main/img/202303231421451.webp)

-   这时我们可以另外找到一条增广路：1->3->2->4。


![v2-b79f3fc5c921de2388012808f8bbed7d_1440w](https://raw.githubusercontent.com/ClearDewy/TyporaImg/main/img/202303231422574.webp)

现在我们同时选择了2->3和3->2两条边，我们可以认为，这两条边上的水流**抵消**了。所以实际上选择的路径就是1->3->4和1->2->4。

其实可以把反向边理解成一种**撤销**，走反向边就意味着撤回上次流经正向边的若干流量，这也合理解释了为什么扣除正向边容量时要给反向边加上相应的容量：反向边的容量意味着可以撤回的量。

## 优化

-   我们只往层数高的方向增广，可以保证不走回头路也不绕圈子。

-   可以使用**多路增广**节省很多花在重复路线上的时间：在某点DFS找到一条增广路后，如果还剩下多余的流量未用，继续在该点DFS尝试找到更多增广路。

-   还有**当前弧优化**。因为在$Dinic$算法中，一条边增广一次后就不会再次增广了，所以下次增广时不需要再考虑这条边。我们把$head$数组复制一份，但不断更新增广的起点。

```cpp
int n,m,s,t;
const int N=5e3+5;
struct edge{
    int to,next;ll w;
}e[N<<1];
int head[N],cur[N],deep[N],ent=1;   // ent^1即为反边

inline void addedge(int x,int y,ll w){
    e[++ent]={y,head[x],w};
    head[x]=ent;
}

bool dinic(){
    queue<int>q;q.push(s);
    memset(deep,0,sizeof deep);
    cur[s]=head[s];
    deep[s]=1;
    int x,y;ll w;
    while(!q.empty()){
        x=q.front();q.pop();
        for(int i=head[x];i;i=e[i].next){
            y=e[i].to;w=e[i].w;
            if (w>0&&!deep[y]){
                deep[y]=deep[x]+1;
                cur[y]=head[y];
                q.push(y);
            }
        }
    }
    return deep[t];
}

ll dfs(int x,ll flow){
    if (x==t)return flow;
    int y;ll resw=flow,w;
    for(int i=cur[x];i && resw;i=e[i].next){
        cur[x]=i;                  // 当前弧优化，更新当前弧;cur为head的备份
        y=e[i].to;w=e[i].w;
        if (w>0&&deep[y]==deep[x]+1){
            w= dfs(y, min(w,resw));
            resw-=w;
            e[i].w-=w;
            e[i^1].w+=w;
        }
    }
    return flow-resw;
}


void ClearDewy(){
    n=read();m=read();s=read();t=read();
    int x,y;ll w;
    for (int i = 0; i < m; ++i) {
        x=read();y=read();w=read();
        addedge(x,y,w);
        addedge(y,x,0);
    }
    ll res=0;
    while(dinic()){                 // 多次增广
        res+= dfs(s,1e18+7);
    }
    writ(res);
}
```
