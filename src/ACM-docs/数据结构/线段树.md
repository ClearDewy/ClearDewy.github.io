# 线段树

## 引入

线段树是算法竞赛中常用的用来维护 **区间信息** 的数据结构。

线段树可以在 的时间复杂度内实现单点修改、区间修改、区间查询（区间求和，求区间最大值，求区间最小值）等操作。

## 建树

![segt1](https://cdn.jsdelivr.net/gh/ClearDewy/TyporaImg/img/202211041725600.svg)

采用递归方式建树，类似二分，递归到单个节点进行赋值等操作，代码如下：

```cpp
inline void build(int h,int l,int r){
    if(l==r){
        change(tr[h]);return;
    }
    int mid=(l+r)>>1;
    build(h<<1,l,mid);
    build(h<<1|1,mid+1,r);
    push_up(h);
}
```

**其中`push_up()`和`push_down()`为数关系操作，常见的有相加，最大最下值等，`change()`为赋值等操作**

## 查询

*查询区间和*

### 区间查询

```cpp
int ql,qr,val;
inline int Query(int h,int l,int r){
    if(ql<=l&&r<=qr){
        return tr[h];
    }
    if(laz[h])push_down(h);
    int mid=(l+r)>>1,res=0;
    if(ql<=mid)res+=Query(h<<1,l,mid);
    if(mid<qr)res+=Query(h<<1|1,mid,r);
    return res;
}
int query(int l,int r,int va){
    ql=l;qr=r;val=va;return Query(1,1,n);
}
```

### 单点查询

在区间查询中将$ql=qr$即可

## 修改

*将$[l,r]$区间中每个数加上$val$*

### 区间修改

$laz[h]$为懒标记，可以减少区间更新次数

```cpp
inline void Update(int h,int l,int r){
    if(ql<=l&&r<=qr){
        tr[h]=tr[h]+val*(r-l+1);
        laz[h]=laz[h]+val;
        return;
    }
    if(laz[h])push_down(h);
    int mid=(l+r)>>1;
    if(ql<=mid)Update(h<<1,l,mid);
    if(mid<qr)Update(h<<1|1,mid,r);
    push_up(h);
}

void update(int l,int r,int va){
    ql=l;qr=r;val=va;Update(1,1,n);
}
```

### 单点修改

在区间修改中将$ql=qr$即可
