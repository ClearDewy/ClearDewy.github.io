# 可持久化线段树

## 主席树

主席树全称是可持久化权值线段树

## 引入

先引入一道题目：给定$n$个整数构成的序列$a$，将对于指定的闭区间$[l,r]$查询其区间内的第$k$小值。

你该如何解决？

一种可行的方案是：使用主席树。 主席树的主要思想就是：保存每次插入操作时的历史版本，以便查询区间第$k$小。

## 实现

![persistent-seg](https://cdn.jsdelivr.net/gh/ClearDewy/TyporaImg/img/202211041800162.png)

如图，在每次更新时新建一条链，每次最多增加$\lceil\log_2n \rceil+1$个节点

-   每次修改后的根节点必不相同
-   在回溯的时候使用一个新的节点，指向当前节点更新后的左孩子和右孩子

用一个数组将每次修改后的根节点编号存下来，然后进行线段树操作即可
